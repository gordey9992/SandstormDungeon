# Sandstorm Dungeon Plugin

Плагин для Minecraft 1.21+ добавляющий данж с песчаной бурей и древним храмом.

## Особенности
- 🌪️ Горизонтальная песчаная буря
- 🏺 Генерация разрушенного храма
- 🧱 Блоки, двигающиеся от ветра
- 💎 Уникальный древний лут

## Команды
- `/sandstorm start` - запустить бурю
- `/sandstorm stop` - остановить бурю
- `/dungeon` - телепорт в данж
