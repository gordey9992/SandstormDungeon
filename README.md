# Песчаный Данж

Плагин для Minecraft 1.21+ добавляющий подземелье с песчаной бурей и древним храмом.

## Особенности
- 🌪️ Горизонтальная песчаная буря
- 🏺 Генерация разрушенного храма  
- 🧱 Блоки, двигающиеся от ветра
- 💎 Уникальный древний лут

## Команды
- `/песчанаябуря старт` - запустить бурю
- `/песчанаябуря стоп` - остановить бурю
- `/данж` - телепорт в подземелье
